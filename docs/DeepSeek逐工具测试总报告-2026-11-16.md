# DeepSeek 逐工具测试总报告（截至 2026-11-16）

## 报告范围与结论

本文把 2026-11-10 开始的 DeepSeek 工具验收、截至 2026-11-14 的 343 用例矩阵、之后的失败项静态修复，以及 2026-11-16 的 56 用例补充模型验收与本轮回归归纳在一起。每个历史用例的原始模型请求、工具参数、事件、终态、前后状态和问题编号仍以证据包为准；本报告不覆盖原始记录。

核心结论：

- 基线验收覆盖 77 个工具身份、343 个用例。矩阵在 2026-11-14 记录为 281 通过、60 失败、2 待完成；随后修复报告的最新快照为 280 通过、61 失败、2 待完成。两份历史快照存在 1 例的状态差异，不能混为同一统计时点。详见 [验收矩阵](DeepSeek逐工具实机验收-2026-11-10/验收矩阵.md)、[343 用例完整报告](DeepSeek逐工具343用例完整报告-2026-11-14.md) 和 [修复与复测报告](DeepSeek逐工具修复与复测报告-2026-11-13.md)。
- 其中 `T022-S01`、`T058-S03` 是需要联机 Host/Farmhand 的用例，按用户指示跳过。其余失败数包含真实实现问题、模型参数不合适、有效场景未准备好、等待超时及覆盖缺口；不能把失败标签一概视为产品代码缺陷。
- 2026-11-16 对独立模型层清单完成了 56/56 项初始覆盖，初核为 41 项符合要求、15 项失败或覆盖不足。随后修复代码并做定向回归；截至本轮结束，已确认 5 项修复回归通过，`T032-S01` 在可靠杂草夹具下也通过。此补充清单不与 343 用例基线简单相加。
- 当前修复后不能宣称 343 个旧失败已全部转绿。历史问题清单里大量修复只完成静态审查和 Release 编译，仍待 DeepSeek 实机回归。
- 当前343项矩阵为298通过、43失败、2待完成。最近的有效隔离测试 run 已切换为 `SC112D_20261116_185438`；Round 6 温泉时间上限用例仍失败，Round 7 温泉正向用例前置状态不合格（实际体力106，高于目标105），不作为通过/失败证据。后续测试交由新会话继续。

### 之前失败用例处理的主题归类

完整逐问题修改说明见修复报告（包含 Q 编号、涉及用例、代码更改、编译/验收状态）。便于新会话快速定位，已修改主题包括：

- 任务与计划衔接：持久目标替换、季维护回执归属、等待条件结束事件、续规划状态校验、取消指定任务身份。
- 原版故事/菜单：提示先脚本处理，阻塞提示和任务终态组合报告；对话选项与普通通知分流；等待不跨菜单。
- 工具结果语义：零产出、部分完成、失败原因、source/target、物品数量和实际资金变化准确报告；拒绝/超时不伪装成功。
- 农场及资源动作：播种数量、灌溉空目标、工具选择、动作结算等待、掉落拾取与剩余掉落追踪、采集来源匹配。
- 经济与库存：制作扣料原子性、授权取料/整理校验、商店按名称及营业条件、订单预算及成交核验。
- 导航、活动与服务：原版 CheckAction 入口、地图切换、节庆、NPC/木匠/动物房路径和菜单结算核验。
- 任务、社交、奖励与博物馆：原生任务身份句柄、奖励实变、赠礼限制原因、Bundle 槽位和博物馆空展位身份。

## 执行约束与判读

- DeepSeek 负责选择并调用被测工具；命令行用于准备隔离夹具、发测试要求、采集请求/事件/终态与核验原版前后状态。
- 全程未使用 Computer Use。用户明确要求用命令行方式测试。
- 接受回执只有在前置状态有效、模型确实调用目标工具且原生状态符合预期时才判通过。
- `accepted/running/progress` 是处理中，不是成功终态。错误夹具或旧目标污染必须单列，不进入产品通过率。
- 本轮相关代码和验收宿主构建均为Release 0警告/0错误；其后仍完成Round 6–7定向模型回归，结果已列于上表。本报告整理期间未继续启动测试。
- Round 7 的终态回执虽然是 `completed/business_completed`，但真实开始体力已超过请求目标；结果不得依据回执单独标成通过。独立用例必须先比对 `before.native.json` 与目标。
