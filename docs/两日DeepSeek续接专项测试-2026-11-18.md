# 两日 DeepSeek 续接专项测试（2026-11-18）

## 结论

隔离的新档完成了两个原版游戏日，存档进入春季第 3 天。续接链路共发起 7 次请求：2 次成功保存续接计划，5 次失败，失败率 71.4%。5 次失败均可复现为 DeepSeek 函数参数 JSON 在字符串中途结束；日志显示这 5 次回复的 `completion_tokens` 都恰好为 650，当前续接调用也将 `maxTokens` 设为 650。这是输出长度上限导致截断的强证据，后续仍应通过提高上限或缩短续接计划后复测确认。

## 测试环境与范围

- 真实桌面端前端、SMAPI 游戏进程和 DeepSeek 自主决策均由命令启动；没有使用 Computer Use，也没有从测试脚本直接派发游戏 tool。
- 新建隔离运行：`.local/solo5/SC2D_20261118_180100/`，独立用户配置和新存档。
- 目标覆盖春季第 1 天与第 2 天，并睡觉进入春季第 3 天。
- 实际存档位置与身份记录在该运行的 `world.json`；决策证据在 `logs/decisions.jsonl`。

## 续接结果

| 续接序号 | 前置任务 | 结果 | 证据序号 |
| --- | --- | --- | --- |
| 1 | `group_farm_management`（领取礼包） | 失败：参数 JSON 未闭合，末尾截断于 `onFailure` | 22、36–37 |
| 2 | `go_to` | 失败：参数 JSON 未闭合，末尾截断于 `onFailure` | 58、64–65 |
| 3 | `group_farm_management`（农活计划） | 失败：参数 JSON 未闭合，截断于 `checksBeforeAction[4]` | 81、99–100 |
| 4 | `group_character_schedule` | 成功保存续接计划 | 189、206 |
| 5 | `water_area` | 成功保存续接计划 | 236、247 |
| 6 | `water_area` | 失败：参数 JSON 未闭合，末尾截断于 `onFailure` | 296、299–300 |
| 7 | `sleep` | 失败：参数 JSON 未闭合，截断于 `nextSteps[3]` | 313、326–327 |

全部 5 个失败回复都达到 650 completion tokens。提取并单独解析日志中保存的 `function.arguments`，均报 `Unterminated string. Expected delimiter: "`，错误位置正好在参数字符串末尾。两次成功回复的计划则通过 JSON 解析并写入 `continuation_planned`。测试期间共 22 次模型请求、22 次回复，没有 `model_error`；因此这批续接失败不是连接中断。

当前实现的续接请求上限位于 `src/StardewCompanion.Core/ContinuousPlanning.cs` 第 78 行（`maxTokens=650`）；解析异常捕获在第 109 行，但日志只保留 `JsonReaderException` 类型名，没有保存消息、堆栈或无敏感信息的参数尾部摘要。这使原始运行难以直接定位；本次通过 `model_reply` 捕获记录补做了参数解析，才确认截断特征。

## 两日流程终态

- 存档经过两次 `day_changed`，到达春季第 3 天；试验按 `configured_native_days_elapsed` 正常暂停。
- 前端 Agent 已暂停，游戏内没有活动任务。最终观察记录为 FarmHouse、春季第 3 天 09:40。
- 最终农场事实记录 10 株健康且已浇水作物，资金仍为 500；第二天是雨天。
- 另有一次 `go_to` 因 FarmHouse 坐标 `(3,12)` 超出室内地图范围而被拒绝，以及一次 `water_area` 因请求区域没有待浇地块而失败。它们不是续接 JSON 错误；当前状态显示作物已浇水，第二天也有降雨。

## 建议的后续代码处理

提高续接响应 token 预算，并限制 `nextSteps`、`assumptions`、`checksBeforeAction` 的总长度；收到不完整 JSON 时记录模型 finish reason、completion token 数、参数字符串长度及末尾有限摘要，然后安全地放弃这次假设并按现有主决策恢复。修改后以同样两日目标复测续接成功率。
