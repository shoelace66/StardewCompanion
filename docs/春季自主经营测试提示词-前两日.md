# 春季自主经营测试提示词（前两日）

自主经营第一年春季。整季策略以春28结束时实测的累计金币收入、季末持有金币与净收益为首要评价，同时争取创造物（已完成建筑、已购买或孵化动物、已取回的工具升级）和村民好感提升。制定并保存覆盖完整春季的季计划，纳入作物成熟与复种周期、春13蛋节草莓投资、商店营业日和时间、资金周转、浇水及劳作体力，并注明未知条件与核验办法。依据季计划、真实观察和执行回执持续选择下一步；计划或订单不算完成，必须以原版状态和成功回执核验。

本轮只执行春1、春2两天。春2夜完成原版保存，进入春3早晨后立即暂停，不执行春3行动；完整春季目标只用于制定季计划和衡量前两天的策略，不得声称已经完成全季经营。

春1必须完成以下起步要求：领取初始礼包并种下全部15颗防风草种子；把初始500g全部优先用于购买土豆种子并将买到的种子全部种下；至少和一位小镇居民实际交流；将体力用于清理农场。先检查当前真实时间、商店营业状态、背包、资金和体力，依据回执安排顺序。春1要求受商店、路径、体力或时间阻碍时，记录具体原因并继续完成其余可行要求，不虚报完成。

严格按商品名称调用购买工具，购买参数使用 `itemName`，不传 `itemId` 或 `QualifiedItemId`；`(O)475` 仅供辨认土豆种子，不是购买参数。本次土豆种子的单价上限为50g、总预算为500g。商店由工具自动寻路并处理开店或短时等候；根据失败回执调整，条件未变时不重复请求，不猜测或替换商品。为春13草莓购买保留长期投资空间，避免前两天无依据地花光后续周转资金。

以居民真实对话回执核验交流。只有已观察确认的喜爱礼物才可赠送，绝不猜测礼物偏好。只有建造完成、动物实际购入或孵化、工具升级取回和好感实际变化才计入成果。每项受阻事项记录状态、回执及恢复条件。前两天结束时只报告已核验事实、未完成要求及其具体原因。
