# 玩家快速开始

## 前置要求

- Windows 10/11 x64。
- Stardew Valley 1.6.15 与 SMAPI 4.5.2（仅 AI 客户端需要 SMAPI）。
- 原版房主和 AI 客户端使用兼容版本；首次测试建议同一台电脑启动两个实例。
- 可以连接玩家自己的 OpenAI 兼容 Chat Completions API。

桌面应用自带 .NET 10 运行时。游戏本身和 SMAPI 需由玩家自行安装。AI 客户端与房主必须能通过游戏的正常联机网络互相连接。

## 首次启动

1. 完整解压桌面程序包，保留 `StardewCompanion.exe` 旁的 `Mods/StardewCompanion.Bridge` 文件夹。桌面程序启动 AI 客户端时会指定这个独立的模组目录。
2. 确认真人通过原版 `Stardew Valley.exe` 启动，建立或主持农场。
3. 打开 Companion，在「设置与工作箱」填入模型接口地址、模型名、密钥和游戏目录，点击「保存设置」。密钥使用当前 Windows 账户 DPAPI 加密；换 Windows 账户后需重新填写。
4. 选择「打开原版房主」或在游戏已运行时直接使用当前房主，然后选择「打开 AI 客户端」。
5. 在 SMAPI 客户端选择「合作」并加入真人房间，首次创建 AI 农场角色可以手动完成。
6. 回到 Companion，核对存档/角色状态并点「继续」。重启 Companion 或重新加入游戏后需再次点击继续。

真人房主必须保持纯原版客户端。不要将本项目控制模组安装到真人房主。

## 工作箱

先让 AI 到包含箱子的地图，在「设置与工作箱」指定其当前格子、名称、允许物品 ID 和保护 ID。箱子搬迁或替换后，原绑定失效，需重新绑定。工具默认不转移；保护 ID 即使同时列入允许项也会被拒绝。

## 控制与记忆

- 「暂停」停止 Agent 派发，并在本机直接停下游戏输入；联机世界仍继续运行。
- 「继续」允许按玩家指令和自主计划执行。游戏/应用重启后会保持暂停。
- 「取消工作」停止当前工作并将长期项目标记取消，除非玩家重新创建，不会自动恢复。
- 待答问题可以回答或移除。未回答/移除不会给予授权。
- 工作记忆按游戏存档与 AI 角色隔离。项目进度由实际回执更新；换日/重进后先重新观察。只有玩家手动「确认项目完成」才会将项目结案。

## 维护

升级前正常退出 Companion 和 AI 客户端，备份 Companion 的本地数据目录及玩家自己的游戏存档。卸载本项目时，删除解压的 Companion 应用目录及本地数据；如果曾手动将控制模组复制到游戏的 SMAPI Mods 目录，也应移除其中的 `StardewCompanion.Bridge`。

模型地址、模型密钥、对话、任务日志和工作记忆保存在本机数据目录。日志记录任务状态和模型耗时/用量，不记录 API 密钥。

默认数据目录是 `%LOCALAPPDATA%\StardewCompanion`；从源码用 `tools/start-desktop.ps1` 启动时使用仓库的 `.local`，也可通过 `--data <目录>` 指定。发布包中的示例配置不会自动替代此目录内的实际设置。

若显示设置文件损坏，程序会先保留一份 `model.credentials.json.invalid-*.bak`，显示备份路径，再使用默认设置打开界面；请重新填写并保存。备份不会因保存设置而删除，保留备份时也应按凭据文件管理。

若本地服务启动失败，先按错误信息处理原因（例如关闭占用 `27841` 的另一个 Companion 或诊断服务），再在设置页点击「重试启动本地服务」。服务未启动时保存设置也会重试启动。重新连接后仍需点击「继续」才会执行工作。
