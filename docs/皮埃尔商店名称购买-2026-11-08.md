# 皮埃尔商店按名称购买

本规则现已推广到其他商店及节日购物，当前完整接口与工具审计见[商店与工具可靠性优化](商店与工具可靠性优化-2026-11-08.md)。

## 调用方式

`purchase_items` 对皮埃尔商店使用 `itemName`。例如：

```json
{
  "location": "Town",
  "shopId": "SeedShop",
  "maxTotal": 500,
  "items": [
    { "itemName": "土豆种子", "count": 10, "maxUnitPrice": 50 }
  ]
}
```

名称匹配当前原版菜单中的本地化显示名或英文内部名称，不做模糊匹配、自动替换或 ID 猜测。中文名称适用于对应中文游戏目录；若名称不匹配，回执提供当前真实目录，模型可以使用目录里的准确名称重试。所有商店的购买统一使用 `itemName`，旧购买 ID 参数在执行前被拒绝。同名商品可用可选 `quality` 明确品质。

## 提示词

全局购买规则替换为：

> 所有商店及节日购物使用商品名称itemName，注意营业时间和活动影响。技能自动寻路、开店，在已知开门前30游戏分钟内等候；失败按回执和真实目录调整，不猜测、替换或无效重试。其他工具的身份标识须来自观察或实际选项目录，同名不明确时先澄清目标。

删除全局重复的物品 ID 提醒和技能说明中的种子 ID 对照表。不强制增加浏览目录调用；购买脚本在原版菜单中匹配商品。自主试跑脚本中的初始目标也改为名称调用。

## 营业和失败回执

| 原因 | 行为 |
| --- | --- |
| `shop_closed_for_day` | 原版周三休息条件成立；检查社区中心事件解锁与城镇钥匙例外 |
| `shop_closed_for_festival` | 原版 `AreStoresClosedForFestival()` 判定当天停业 |
| `shop_not_open_yet` | 距离开门超过30游戏分钟，立即返回；提供最早可进入短时等候窗口的时间 |
| 等候中 | 剩余时间不超过30游戏分钟，自动接近入口并等候；不修改游戏时间，可暂停取消 |
| `shop_closed_for_today` | 已超过已确认的柜台营业时间；下一次营业时间未知时保持未知 |
| `shop_owner_unavailable` | 原版开店交互失败，当前可服务店员不可用；不将所有店员离开都认定为停业 |
| `shop_interaction_failed` | 柜台交互最多尝试两次后仍没有商店菜单；不再回报为关门 |
| `shop_item_name_not_in_catalog` | 当前目录没有该名称；返回完整真实目录，不断言物品不存在或季节限制 |
| `shop_item_name_ambiguous` | 多个商品匹配相同名称；返回目录，禁止自动任选 |
| `shop_item_sold_out` / `shop_stock_insufficient` | 当前库存不足，不擅自降低请求数量 |
| `shop_item_no_longer_available` | 选定商品在交易期间消失，返回剩余数量与最新目录 |

营业时间优先读取原版 `OpenShop` 柜台 Action 中的时间。旧版 `Buy` 柜台兼容皮埃尔原版09:00–17:00服务窗口，并在回执标注来源；无法确认时间的柜台保持时间未知。已经打开的真实商店菜单优先作为可交易事实，不被时间推断覆盖。

旧版 `Buy` 柜台从顾客侧接近，避免角色站在柜台内侧时被原版店员位置检查拒绝。原版钱箱提示继续确认并等待游戏自己的开店回调，不强行打开商店。需要选择的对话返回模型。

回执保留执行阶段、日期、时刻、原版提示、恢复条件、已确认购买数量及实际支出。中断购买时，正在执行的交易进度也进入回执。重复失败请求在相关状态未变化时被拦截；跨过短时等候窗口、换日或原版周三营业解锁状态变化后允许重新核验。
